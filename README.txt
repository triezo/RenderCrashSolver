RenderSolver 1.0
================

Очередь рендера для Blender. Ставите несколько сцен — они рендерятся по
очереди. Если Blender упал или завис, программа сама перезапускает его и
продолжает с первого недостающего кадра, готовые кадры не трогает.
До версии 0.6 программа называлась RenderCrashSolver.


ЧТО НУЖНО
---------
- Windows 10 или 11. Ничего дополнительно устанавливать не нужно: программа
  работает на .NET Framework 4, который уже встроен в Windows 10 и 11.
  (На Windows 7/8 может понадобиться поставить .NET Framework 4.8 с сайта
  Microsoft.)
- Blender 2.8 или новее (проверено на 4.3 и 5.2).
- В сцене вывод должен быть последовательностью кадров (JPG, PNG, EXR...),
  а не видеофайлом: Output Properties -> Output -> File Format.


УСТАНОВКА
---------
Есть два варианта, программа в них одна и та же.

Установщик (RenderSolver_Setup_1.0.exe) — для обычной работы:
1. Запустите RenderSolver_Setup_1.0.exe и нажмите "Установить".
   Права администратора не нужны: программа ставится только для вас, в
   папку %LOCALAPPDATA%\Programs\RenderSolver.
2. RenderSolver появится в меню "Пуск" (и на рабочем столе, если оставить
   галочку). Новую версию ставьте тем же способом поверх: очередь и
   настройки сохранятся.
3. Удалить: Параметры -> Приложения -> Установленные приложения ->
   RenderSolver -> Удалить.

Без установки (RenderSolver_1.0_portable.zip) — например, для флешки или
рендер-машины, где ничего нельзя ставить:
1. Распакуйте архив в любую папку и запустите RenderSolver.exe. Это один
   файл, больше ему ничего не нужно.
2. Очередь и настройки хранятся в settings.ini рядом с программой —
   папку можно переносить целиком.

Обновляетесь с 0.6 или RenderCrashSolver, которые распаковывали из zip?
- Проще всего положить новый RenderSolver.exe в старую папку вместо
  прежнего: очередь и настройки подхватятся сами. Файл resume_render.py
  там больше не нужен, его можно удалить (теперь он встроен в программу).
- Если переходите на установщик: после установки скопируйте settings.ini
  из старой папки в %LOCALAPPDATA%\Programs\RenderSolver (при закрытой
  программе), чтобы очередь перенеслась.

При первом запуске Windows может показать синее окно "Система Windows
защитила ваш компьютер" (программа не подписана платной цифровой подписью).
Нажмите "Подробнее" -> "Выполнить в любом случае". Это нужно сделать один раз.


КАК ПОЛЬЗОВАТЬСЯ
----------------
1. Blender.exe находится автоматически. Если нет или нужна другая версия,
   укажите его на вкладке "Настройки".
2. На вкладке "Очередь" добавьте сцены: кнопка "Добавить" или перетащите
   .blend файлы (или папку со сценами) прямо в список.
   Через несколько секунд у каждой сцены появятся диапазон кадров и сколько
   кадров уже готово.
3. Галочка у сцены — рендерить её или нет. Порядок меняется перетаскиванием
   строк или стрелками под списком.
4. Нажмите на сцену, чтобы настроить её внизу: "Свои кадры",
   "Другая папка вывода" (рендер в другую папку или с другим именем файла,
   сам .blend не меняется), "Override".
5. Нажмите "Старт" (вверху справа) или F5. Окно можно свернуть, но не
   закрывайте его до конца рендера. Прогресс виден и на кнопке программы
   в панели задач: синий — рендер, жёлтый — ждёт перезапуска, красный — ошибка.


КАК РАБОТАЕТ ОЧЕРЕДЬ
--------------------
- Сцены рендерятся сверху вниз, по одной.
- Если у сцены все кадры уже на диске, она сразу отмечается "ГОТОВО"
  и Blender для неё не запускается.
- Если сцена закончилась ошибкой (лимит попыток, ошибка в сцене),
  она отмечается красным, а очередь переходит к следующей.
- Пока очередь идёт, можно добавлять сцены в конец и менять настройки
  сцен, которые ещё ждут. Сцену, которая рендерится сейчас, менять нельзя.
- "Стоп" останавливает текущую сцену и всю очередь, Blender закрывается
  и освобождает память. Следующий "Старт" продолжит с недостающих кадров —
  это и есть пауза.
- "Осталось" вверху — примерное время до конца всей очереди и во сколько
  она закончится. Время кадра каждая сцена запоминает со своего прошлого
  рендера; у новых сцен берётся время текущего рендера. Знак "≥" значит,
  что для части сцен данных ещё нет. У каждой сцены в списке — её время.
- Правый клик по сцене: открыть папку рендера, открыть сцену в Blender,
  дублировать (например, чтобы отрендерить ту же сцену с другими кадрами).


СВОИ КАДРЫ
----------
По умолчанию рендерится диапазон кадров из сцены (с шагом сцены, если он
задан). Чтобы отрендерить только часть, включите "Свои кадры" и перечислите
кадры через запятую или пробел, например:

    1-100, 120, 150-200

Под полем видно, сколько кадров выбрано. Всё остальное работает как обычно:
готовые кадры не перерендериваются, после краша рендер продолжается,
с Override перерендериваются только выбранные кадры.


OVERRIDE — ПЕРЕРЕНДЕРИТЬ ВСЁ ЗАНОВО
----------------------------------
Обычно кадры, которые уже лежат в папке вывода, считаются готовыми и не
рендерятся повторно. Если сцену поменяли и нужно отрендерить её заново,
поставьте у неё галочку "Override" и нажмите "Старт" (программа спросит
подтверждение).

- Старые кадры перезаписываются по ходу рендера, заранее ничего не удаляется.
- Если Blender упадёт, вы нажмёте "Стоп" или выключите компьютер, при
  следующем "Старте" перерендер продолжится с места остановки, а не начнётся
  сначала: уже перерендеренные кадры повторно не рендерятся.
- Когда все кадры сцены готовы, галочка снимается сама.
- Если снять галочку вручную, перерендер отменяется: оставшиеся старые кадры
  снова считаются готовыми.

Справа — просмотр кадров: последний готовый кадр, ползунок для перемотки,
кнопка проигрывания подряд (удобно ловить мерцание и артефакты),
двойной клик — открыть кадр в полном размере. После клика по кадру
стрелки влево/вправо листают кадры, пробел включает проигрывание.
Под просмотром — журнал: ошибки красным, предупреждения жёлтым.


ЧТО ПРОИСХОДИТ АВТОМАТИЧЕСКИ
----------------------------
- Blender упал -> пауза (по умолчанию 10 с) и перезапуск с недостающего кадра.
- Нет нового кадра дольше заданного времени (по умолчанию 60 мин) ->
  Blender считается зависшим, его перезапускают. Если у вас один кадр
  рендерится дольше часа — увеличьте это время на вкладке "Настройки".
- Уже готовые кадры не перерендериваются, даже если есть "дыры" в середине.
- Битые кадры (файл оборвался при краше) переименовываются в *.broken
  и рендерятся заново.
- Пока идёт рендер, компьютер не уходит в сон.


ФАЙЛЫ
-----
- settings.ini — ваши настройки и очередь, создаётся рядом с программой
  (после установщика — в %LOCALAPPDATA%\Programs\RenderSolver).
- logs\ — полный лог Blender по дням (render_log_ГГГГММДД.txt), там же.
  Если что-то пошло не так — пришлите этот лог и скриншот окна.
- %LOCALAPPDATA%\RenderSolver\resume_render.py — скрипт для Blender.
  Программа сама кладёт его туда из себя при запуске рендера, трогать
  его не нужно.


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
- Программа не запускается и Windows пишет про .NET Framework — такое
  возможно только на старых Windows 7/8: поставьте .NET Framework 4.8
  с сайта Microsoft. На Windows 10/11 он уже есть.
- "Не удалось прочитать сцену" — проверьте путь к blender.exe и что .blend
  открывается в Blender обычным способом.
- Сцена "читается" в Blender только при добавлении и после того, как .blend
  сохранили заново. Пока она читается, Blender ненадолго занимает память,
  как при открытии сцены.
- "Ошибка в resume_render.py (код 2)" — чаще всего в сцене выбран вывод
  в видео (FFMPEG). Переключите на JPG/PNG/EXR.
- Антивирус ругается на exe — это ложное срабатывание на неподписанную
  программу, добавьте её в исключения.

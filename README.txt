RenderCrashSolver 0.1 (тестовая версия)
========================================

Рендерит анимацию Blender и сам продолжает её после краша: перезапускает
Blender и начинает с первого недостающего кадра, готовые кадры не трогает.


ЧТО НУЖНО
---------
- Windows 10 или 11. Ничего дополнительно устанавливать не нужно.
- Blender 2.8 или новее (проверено на 4.3).
- В сцене вывод должен быть последовательностью кадров (JPG, PNG, EXR...),
  а не видеофайлом: Output Properties -> Output -> File Format.


ПЕРВЫЙ ЗАПУСК
-------------
1. Распакуйте архив ЦЕЛИКОМ в обычную папку. Не запускайте программу прямо
   из zip — она не найдёт resume_render.py.
2. Запустите RenderCrashSolver.exe.
3. Windows может показать синее окно "Система Windows защитила ваш компьютер"
   (программа не подписана платной цифровой подписью). Нажмите
   "Подробнее" -> "Выполнить в любом случае". Это нужно сделать один раз.


КАК ПОЛЬЗОВАТЬСЯ
----------------
1. Blender.exe — находится автоматически. Если нет или нужна другая версия,
   укажите вручную кнопкой "...".
2. Сцена .blend — выберите файл сцены.
   Через несколько секунд в строке "Вывод (сцена)" появится путь рендера из
   сцены, диапазон кадров и сколько кадров уже готово.
3. При желании включите "Свой путь вывода", чтобы рендерить в другую папку
   или с другим именем файла. Сам .blend при этом не меняется.
4. Нажмите "Старт". Окно можно свернуть, но не закрывайте его до конца рендера.

Справа — просмотр кадров: последний готовый кадр, ползунок для перемотки,
"Играть" — проигрывание подряд (удобно ловить мерцание и артефакты),
двойной клик — открыть кадр в полном размере.


ЧТО ПРОИСХОДИТ АВТОМАТИЧЕСКИ
----------------------------
- Blender упал -> пауза (по умолчанию 10 с) и перезапуск с недостающего кадра.
- Нет нового кадра дольше заданного времени (по умолчанию 60 мин) ->
  Blender считается зависшим, его перезапускают. Если у вас один кадр
  рендерится дольше часа — увеличьте это время.
- Уже готовые кадры не перерендериваются, даже если есть "дыры" в середине.
- Битые кадры (файл оборвался при краше) переименовываются в *.broken
  и рендерятся заново.
- Пока идёт рендер, компьютер не уходит в сон.


ФАЙЛЫ
-----
- settings.ini — ваши настройки, создаётся рядом с программой.
- logs\ — полный лог Blender по дням (render_log_ГГГГММДД.txt).
  Если что-то пошло не так — пришлите этот лог и скриншот окна.


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
-----------------------
- "Не удалось прочитать сцену" — проверьте путь к blender.exe и что .blend
  открывается в Blender обычным способом.
- "Ошибка в resume_render.py (код 2)" — чаще всего в сцене выбран вывод
  в видео (FFMPEG). Переключите на JPG/PNG/EXR.
- Антивирус ругается на exe — это ложное срабатывание на неподписанную
  программу, добавьте её в исключения.

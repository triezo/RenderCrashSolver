# RenderCrashSolver

Рендер анимации Blender, который сам продолжается после краша. Если Blender упал или завис, программа перезапускает его и продолжает с первого недостающего кадра, а уже готовые кадры не трогает.

## Возможности

- **Автоперезапуск** после краша Blender, с паузой и лимитом попыток.
- **Watchdog.** Если слишком долго нет нового кадра, Blender считается зависшим и перезапускается.
- **Готовые кадры не перерендериваются**, даже если есть «дыры» в середине диапазона.
- **Битые кадры** (файл оборвался при краше) находятся по маркеру конца JPG/PNG и рендерятся заново.
- **Путь вывода** читается из `.blend`. При желании можно задать свой путь, сама сцена при этом не меняется.
- **Прогресс:** кадр N из M, среднее время кадра, примерное время до конца.
- **Просмотр кадров:** последний готовый кадр, перемотка, проигрывание подряд, чтобы ловить мерцание и артефакты.
- **Короткий лог** в окне: повторяющиеся предупреждения показываются один раз. Полный лог пишется в файл.
- Пока идёт рендер, компьютер не уходит в сон.

## Требования

- Windows 10/11 (.NET Framework 4 уже встроен в систему).
- Blender 2.8+ (проверено на 4.3).
- Вывод сцены — последовательность кадров (JPG/PNG/EXR…), не видео.

## Использование

Возьмите готовый zip в разделе Releases (если он там есть) или соберите сам через `package.bat` (см. ниже). Распакуйте архив целиком и запустите `RenderCrashSolver.exe`. Подробная инструкция — в [README.txt](README.txt).

## Сборка

Ничего устанавливать не нужно: используется компилятор C#, встроенный в Windows.

| Скрипт | Что делает |
|---|---|
| `build.bat` | Собирает `RenderCrashSolver.exe` рядом с исходниками (с уведомлениями в Telegram, `/define:TELEGRAM`). |
| `package.bat` | Собирает тестовую сборку в `dist\RenderCrashSolver\` и zip-архив для раздачи (без Telegram). |

## Устройство

| Файл | Роль |
|---|---|
| `RenderCrashSolver.cs` | Главное окно: настройки, запуск Blender, перезапуски, watchdog, разбор вывода, лог. |
| `PreviewPanel.cs` | Панель просмотра готовых кадров. |
| `Telegram.cs` | Уведомления через Telegram-бота (в разработке). |
| `resume_render.py` | Скрипт внутри Blender (`blender -b scene.blend -P resume_render.py`): находит готовые кадры, рендерит недостающие, печатает служебные строки `[resume_render] ...` для окна. |
